Preview Markdown and source files without sending your files anywhere.

Use Open File or Open Folder for local Markdown and source files. Enable file:// URL access only when you want Chrome to automatically open local developer file links with this extension.

Recommended

Open File / Open Folder

This is the easiest local-file workflow. The user chooses a file or folder, then Dev File Viewer reads only that selected content.

  • No file:// setting required
  • Works well for non-technical users
  • Best fit for privacy-first local preview
